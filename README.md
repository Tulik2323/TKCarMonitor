# ניטור נהיגה (TKCarMonitor)

מערכת לניטור נהיגה של נהג צעיר. טלפון Android ייעודי מותקן ברכב שולח אירועים לשרת בענן, והדשבורד מציג אותם בדפדפן מכל מקום.

## מבנה

```
android/   אפליקציית Android (Kotlin) שרצה בטלפון שברכב
server/    שרת Node.js: מקבל אירועים, שומר אותם, ומגיש את הדשבורד
```

## אירועים שמזוהים

| אירוע | מקור | ברירת מחדל |
|---|---|---|
| בלימה פתאומית | שינוי מהירות GPS | 0.4g |
| האצה חזקה | שינוי מהירות GPS | 0.35g |
| פנייה חדה / החלקה | מהירות × קצב סיבוב (ג'ירוסקופ) | 0.35g |
| מהירות מעל הגבול | מהירות GPS | 110 קמ"ש (ניתן לשינוי באפליקציה) |
| תאונה / פגיעה | תאוצה ליניארית של חיישן התאוצה | 4g |

כל סוג אירוע מוגבל לאירוע אחד בכל 10 שניות, כדי שזעזוע אחד לא ייצור עשרות התראות.

**לא נכלל:** זיהוי שימוש בטלפון של הבת עצמה. טלפון שמותקן ברכב לא רואה מה קורה במסך של הטלפון השני, ולכן אין לו דרך אמינה לזהות זאת.

## שרת ודשבורד

### הרצה מקומית

```bash
cd server
export DEVICE_TOKEN="$(openssl rand -hex 24)"
export DASHBOARD_TOKEN="$(openssl rand -hex 24)"
npm start
```

פתחו את `http://localhost:8080` והזינו את `DASHBOARD_TOKEN`. את `DEVICE_TOKEN` תזינו באפליקציה ב-Android.

### שמירת נתונים

אירועים ומסלולים נשמרים **שבועיים** (14 יום) ואז נמחקים אוטומטית. אפשר לשנות עם `RETENTION_DAYS`.

### בדיקות

```bash
cd server
npm test
```

### פריסה לענן

השרת הוא שירות Node.js יחיד ללא תלויות חיצוניות. כל ספק שמריץ Node 20+ יתאים (Render, Fly.io, Railway, VPS וכדומה).

- הגדירו את `DEVICE_TOKEN` ו-`DASHBOARD_TOKEN` כמשתני סביבה.
- הגדירו `DATA_DIR` לתיקייה שנשמרת בין הפעלות (דיסק מתמיד). בלעדיה האירועים יימחקו בכל פריסה מחדש.
- השרת צריך תהליך שרץ ברציפות (לשידור חי ולכתיבה לדיסק). פלטפורמות serverless כמו Netlify Functions לא מתאימות לכך.
- ודאו שהשירות זמין ב-HTTPS. האפליקציה לא תשלח נתונים ל-`http://`.

## אפליקציית Android

### בנייה

הפרויקט נכתב עם Android Gradle Plugin 8.5 ו-Kotlin 1.9. נדרש Android Studio (או Android SDK עם API 34).

1. פתחו את התיקייה `android/` ב-Android Studio.
2. הריצו `gradle wrapper` פעם אחת כדי ליצור את ה-wrapper (הוא לא נשמר במאגר).
3. בנייה: `./gradlew assembleDebug`. בדיקות יחידה: `./gradlew testDebugUnitTest`.

### התקנה בטלפון ברכב

1. התקינו את ה-APK על טלפון Android 11 ומעלה, והכניסו SIM עם חבילת דאטה.
2. פתחו את האפליקציה, הזינו כתובת שרת (`https://...`), סיסמת מכשיר ומהירות מותרת, ולחצו **שמור והפעל ניטור**.
3. אשרו הרשאת מיקום ("בזמן השימוש באפליקציה" מספיק) והתראות.
4. **חשוב:** בהגדרות הטלפון, כבו את "אופטימיזציית סוללה" לאפליקציה (Settings → Apps → ניטור נהיגה → Battery → Unrestricted). בלי זה אנדרואיד עלול לעצור את השירות.
5. חברו את הטלפון לחשמל והצמידו אותו למחזיק לשמשה, כך שהחיישנים יישבו יציב.

### הפעלה מחדש

אחרי הפעלה מחדש של הטלפון, השירות מתחיל אוטומטית אם הניטור היה פעיל. ב-Android 12 ומעלה ייתכן שהמערכת תחסום זאת. במקרה כזה פתחו את האפליקציה ידנית.

## הגבלות ידועות

- **תאונה:** הזיהוי מבוסס על חיישן הטלפון במחזיק. זעזועים חזקים מכביש גס עלולים לזהות כתאונה (זיהוי שגוי). אפשר להעלות את הסף ב-`DrivingDetector.kt`.
- **מהירות:** GPS לא תמיד מדויק, במיוחד בתוך מנהרות או בין בניינים גבוהים.
- **דאטה ללא קליטה:** אירועים נשמרים במכשיר ונשלחים כשהחיבור חוזר. אין הגבלה על גודל התור.
